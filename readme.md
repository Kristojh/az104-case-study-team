# Contoso Coffee – AZ-104 Case Study 0

This repository contains the solution for the **Contoso Coffee AZ-104 Case Study 0**.

The goal of the project is to design and deploy a cost-effective Azure solution for the Contoso Coffee website, including web hosting, storage, identity, access control and infrastructure deployment.

## Project Components

The solution includes:

* Azure App Service for hosting the Contoso Coffee website
* Deployment of the website in multiple Azure regions
* Traffic Manager for global traffic distribution
* Azure Storage for images and other website content
* Blob Storage lifecycle management
* Shared Access Signature (SAS) for controlled access to stored images
* Microsoft Entra ID and Azure RBAC for identity and access management
* ARM templates for infrastructure deployment
* GitHub for source control and collaboration
